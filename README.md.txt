# Exemplo Prático: Framework Astro

> Trabalho de Seminário — Disciplina de Desenvolvimento Web I

## Descrição
Este repositório contém um projeto minimalista desenvolvido com o framework **Astro**, demonstrando seus principais conceitos: componentização, conteúdo estático por padrão e ilhas de hidratação.

## Conceitos Demonstrados
- **Componentização:** Cada parte da página é um arquivo independente e reutilizável
- **Layouts:** Estrutura padrão usada em todas as páginas
- **HTML por padrão:** O Astro envia só HTML para o navegador, sem JavaScript desnecessário

## Estrutura do Projeto
seminario-astro/
|---scr/
|   |---componentes/
|   |---layouts/
|   |---index.astro
|---astro.config.mjs
|---package.json

## Como executar

1. instale as dependências: 
npm install

2. Inicie o navegador:
npm run dev

3. Acesse o navegador:
http://localhost:4321
